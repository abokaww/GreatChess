# GreatChess ♟️

**Что я сделал:**
Я разработал полноценное веб-приложение для игры в шахматы — GreatChess. Это не просто интерактивная шахматная доска, а готовый продукт (прототип стартапа) с продуманным интерфейсом и облачной архитектурой. Приложение поддерживает авторизацию, умного ИИ-соперника, систему ИИ-Коуча для разбора партий, локальный режим игры и сохранение прогресса. База данных, аутентификация и хранение истории матчей реализованы на базе Supabase.

**Для кого это:**
Для любителей шахмат любого уровня. Новичкам приложение предлагает ИИ-коуча, который помогает разбирать ошибки и учиться. Опытные игроки оценят чистый минималистичный дизайн, систему трекинга рейтинга (Elo) и возможность кастомизации (темы фигур и доски).

**Почему это ценно:**
Проект решает проблему скучных и перегруженных шахматных платформ, предлагая современный, интуитивно понятный интерфейс. Интеграция с ИИ дает пользователям персонального тренера, что повышает ценность продукта. Кроме того, в приложении заложена бизнес-логика (например, раздел "PRO Тариф" и кастомные визуальные темы), что показывает коммерческий потенциал проекта для удержания и монетизации аудитории.

**Основные фичи:**
- 🔐 Авторизация пользователей через Google (Supabase Auth).
- 🤖 ИИ-соперник и умный ИИ-Коуч для анализа ходов.
- 👥 Локальный режим игры за одним устройством (с переворотом доски).
- ☁️ Облачное сохранение недоигранных партий — можно продолжить с любого устройства.
- 📈 Система рейтингов (Elo) и профили игроков.
- 🎨 Глубокая кастомизация визуала (разные стили досок и фигур).
