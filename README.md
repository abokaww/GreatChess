# GreatChess

Этот проект использует `@tanstack/react-start` и работает локально через Vite.

## Быстрый запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите локальный сервер разработки:

```bash
npm run dev
```

3. Соберите проект для локального тестирования:

```bash
npm run build
```

4. Просмотрите собранную версию:

```bash
npm run preview
```

## Полезные команды

- `npm run dev` — запуск локального Vite для разработки.
- `npm run build` — сборка проекта.
- `npm run preview` — просмотр собранной версии.
